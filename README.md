# Schola Sainte-Odile

Public website of the Schola Sainte-Odile, Gregorian chant choir of the église Sainte-Odile (Paris 17e).
Served by GitHub Pages at https://scholasainteodile.fr/ (custom domain, DNS at Gandi; the CNAME file must stay).

Page bodies live in `pages/*.html`; run `python3 build.py` to regenerate the root pages with the shared header and footer.
The password-protected choristers space lives in the `espace-choristes` repository.
